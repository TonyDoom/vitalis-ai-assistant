# Vitalis AI Assistant

Asistente virtual para consultas administrativas de Clínica Vitalis Salud.

## Funciones

- Consulta de tarifas en pesos mexicanos.
- Consulta de especialidades, sedes y horarios.
- Búsqueda semántica sobre documentos internos con FAISS.
- Integración con Gemini y LangChain.
- Backend con FastAPI.
- Interfaz web con Streamlit.
- Ejecución con Docker Compose.
